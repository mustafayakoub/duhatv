## 📂 بنية قاعدة البيانات:

### **بدون تكرار:**

```sql
-- جدول الآيات الأساسية (مرة واحدة فقط)
ayahs: 6,236 صف
  - id (مفتاح أساسي)
  - sura_no (1-114)
  - aya_no (رقم الآية)
  - jozz, page, line_start, line_end

-- جدول النسخ المختلفة
text_versions: 7 صفوف (أو أكثر)
  - id (مثلاً: 'hafs', 'warsh', 'tajweed')
  - name (الاسم الكامل)
  - description

-- جدول النصوص (متعدد)
ayah_texts: 6,236 × 7 = 43,652 صف
  - ayah_id (مرجع للآية)
  - version_id (مرجع للنسخة)
  - aya_text (النص الأصلي)
  - aya_text_emlaey (النص الإملائي)
  - search_text (للبحث)
  - word_count, letter_count
```

**لماذا لا يوجد تكرار؟**
- الآية الواحدة تُخزن **مرة واحدة** في جدول `ayahs`
- النصوص المختلفة تُخزن في جدول منفصل `ayah_texts` مع `version_id`
- **فصل البيانات الأساسية عن المحتوى** = لا تكرار!

- **السبب:** أنت في مجلد خاطئ

