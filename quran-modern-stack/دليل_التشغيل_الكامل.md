# 🌙 Quran Modern Stack - دليل التشغيل الكامل

---

# 🎯 ما هو هذا المشروع؟

**Quran Modern Stack** هو نظام قرآني متكامل يجمع بين **ثلاث لغات برمجية حديثة**:

1. **🦀 Rust** - Backend API فائق السرعة (أسرع 100 مرة من Python)
2. **🐹 Go** - Microservice للبحث في النص القرآني
3. **⚛️ TypeScript/React** - واجهة ويب عصرية وجميلة

**الهدف:** دمج 3 قواعد بيانات SQLite في قاعدة PostgreSQL موحدة وحديثة مع دعم كامل للعربية.

# ✨ المميزات الرئيسية

## 🦀 Rust Backend (Port 8000)

- ⚡ **أداء خارق** - Axum framework مع async/await
- 🔒 **Type-safe** - SQLx مع compile-time checks
- 💾 **Caching ذكي** - Redis للاستعلامات المتكررة
- 🌍 **دعم كامل للعربية** - UTF-8 في كل مكان
- 📦 **Docker optimized** - Multi-stage build (~10 MB)

**Endpoints:**
- `GET /api/surahs` - قائمة السور
- `GET /api/surahs/:id` - سورة محددة مع آياتها
- `GET /api/ayahs/:id` - آية محددة
- `GET /health` - حالة الخدمة

## 🐹 Go Search Service (Port 8001)

- 🔍 **Full-text search** - PostgreSQL tsvector
- 🎯 **تطبيع النص العربي** - إزالة التشكيل تلقائياً
- 🔎 **Similar search** - Trigram similarity
- ⚡ **سريع جداً** - 10-20ms للاستعلام
- 💾 **Redis caching** - تخزين النتائج

**Endpoints:**
- `GET /api/search?q=الله` - بحث نصي
- `GET /api/similar?text=...` - آيات مشابهة
- `GET /api/suggest?q=...` - اقتراحات تلقائية
- `GET /health` - حالة الخدمة
- `GET /metrics` - إحصائيات الأداء

## ⚛️ TypeScript Frontend (Port 3000)

- 🎨 **Material-UI v5** - تصميم عصري
- 🔄 **RTL Support** - دعم كامل للعربية
- 🌓 **Dark/Light Mode** - وضع ليلي/نهاري
- 📱 **Responsive** - يعمل على جميع الأجهزة
- ✍️ **خطوط عربية جميلة** - Amiri, Cairo, Scheherazade
- ⚡ **React Query** - caching ذكي للبيانات

**الصفحات:**
- **Home** - قائمة 114 سورة
- **Surah Detail** - عرض السورة كاملة
- **Search** - بحث في القرآن
- **Settings** - الإعدادات (حجم الخط، الوضع الليلي، إلخ)

# 🐛 حل المشاكل الشائعة

## ❌ "Docker غير مثبت"

**الحل:**
1. حمّل Docker Desktop: https://www.docker.com/products/docker-desktop/
2. ثبته وافتحه
3. انتظر حتى يظهر "Docker is running"

---

## ❌ "المنفذ مشغول" (Port already in use)

**السبب:** خدمة أخرى تستخدم نفس المنفذ

**الحل:**

```bash
# لإيقاف الخدمة المشغولة على المنفذ 5432 (مثلاً):
# Windows:
netstat -ano | findstr :5432
taskkill /PID <PID> /F

# Linux/Mac:
lsof -i :5432
kill -9 <PID>
```

أو غيّر المنفذ في `docker-compose.yml`:

```yaml
ports:
  - "5433:5432"  # بدل 5432 إلى 5433
```

---

## ❌ "unable to open database file"

**السبب:** Docker لا يستطيع الوصول لقواعد البيانات

**الحل:**

1. تأكد من المسار صحيح في `docker-compose.yml`:
   ```yaml
   volumes:
     - C:/quran11:/source-dbs:ro
   ```

2. تأكد من وجود الملفات:
   ```bash
   ls C:\quran11\
   ```

3. في Docker Desktop، اذهب لـ Settings → Resources → File Sharing
   وتأكد من إضافة `C:\quran11\`

---

## ❌ "connection refused" عند الاتصال بالـ API

**السبب:** الخدمة لم تبدأ بعد

**الحل:**

```bash
# تحقق من حالة الخدمات:
docker-compose ps

# شاهد اللوجز:
docker-compose logs backend-rust
docker-compose logs search-service-go

# أعد تشغيل الخدمة:
docker-compose restart backend-rust
```

## ❌ بناء Frontend/Go يفشل

**السبب:** مشاكل في الاتصال بالإنترنت أثناء تحميل Dependencies

**الحل:**

```bash
# أعد البناء بدون cache:
docker-compose build --no-cache frontend

# ثم شغّل:
```
