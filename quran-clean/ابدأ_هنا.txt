📋 المتطلبات:
  • ملفات البيانات في المجلد: C:\Qgo3\
  • Python 3.8+ مثبت
  • WSL (Ubuntu) مثبت
  • متصفح ويب حديث

═══════════════════════════════════════════════════════════════

🚀 طريقة التشغيل (خطوتان فقط):

┌───────────────────────────────────────────────────────────────┐
│ الطريقة الأولى: تلقائية (موصى بها) ✨                         │
└───────────────────────────────────────────────────────────────┘

1. افتح PowerShell في مجلد C:\Qgo
2. نفّذ الأمر التالي:

   powershell -ExecutionPolicy Bypass -File "\\wsl$\Ubuntu\home\user\duhatv\quran-clean\COPY_FILES.ps1"

3. بعد انتهاء النسخ، شغّل:

   \\wsl$\Ubuntu\home\user\duhatv\quran-clean\RUN_ALL.bat

4. انتظر 5-10 دقائق (استيراد البيانات)
5. افتح المتصفح: http://localhost:5000

═══════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────┐
│ الطريقة الثانية: يدوية 🔧                                     │
└───────────────────────────────────────────────────────────────┘

1️⃣  نسخ الملفات:
   انسخ جميع الملفات من C:\Qgo3\ إلى:
   \\wsl$\Ubuntu\home\user\duhatv\quran-clean\data\

   المجلدات المطلوبة:
   ├── ayat\     (18 ملف نصوص القرآن)
   ├── surahs\   (ملف Excel السور)
   ├── words\    (6 ملفات الكلمات والإعراب)
   └── fonts\    (16 خط)

2️⃣  تثبيت المتطلبات:
   wsl bash -c "cd /home/user/duhatv/quran-clean && pip install -r requirements.txt"

3️⃣  استيراد البيانات (5-10 دقائق):
   wsl bash -c "cd /home/user/duhatv/quran-clean && python import_data.py"

4️⃣  تشغيل التطبيق:
   wsl bash -c "cd /home/user/duhatv/quran-clean && python app.py"

5️⃣  افتح المتصفح:
   http://localhost:5000

✨ ميزات التطبيق:

📖 18 قراءة ونمط قرآني في قائمة واحدة منظمة:
   • الرسم الأول (AlAwwal)
   • الرسم العثماني الكامل
   • الرسم العثماني المبسط
   • 6 قراءات (حفص، ورش، قالون، الدوري، شعبة، السوسي)
   • 9 أنماط أخرى (إملائي، عجمي، لاتيني، تجويد...)

🔍 4 أنواع بحث متقدم:
   • بحث نصي عادي
   • بحث بالجذر
   • بحث بالإعراب
   • بحث بالمعنى

📝 علوم القرآن المتكاملة:
   • إعراب كل كلمة
   • صرف وتفاصيل نحوية
   • معاني الكلمات
   • الرسم القرآني
   • إحصائيات الكلمات

🎨 واجهة أنيقة:
   • تصميم نظيف وحديث
   • أزرار دائرية صغيرة
   • ألوان هادئة
   • سهل الاستخدام

🔤 16 خط عربي:
   • خطوط عثمانية احترافية
   • تحكم كامل بحجم الخط
   • حفظ الإعدادات تلقائياً

⚠️  حل المشاكل الشائعة:

❌ خطأ: "No such file or directory"
   ✅ تأكد من نسخ الملفات أولاً باستخدام COPY_FILES.ps1

❌ خطأ: "ModuleNotFoundError: No module named 'flask'"
   ✅ شغّل: pip install -r requirements.txt

❌ خطأ: "Address already in use"
   ✅ أوقف أي تطبيق يعمل على المنفذ 5000
   ✅ أو غيّر المنفذ في app.py

❌ الخطوط لا تظهر
   ✅ تأكد من نسخ الخطوط إلى مجلد static/fonts/

❌ البيانات لا تظهر
   ✅ تأكد من تشغيل import_data.py بنجاح
   ✅ تحقق من وجود ملف quran.db
