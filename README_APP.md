## 🚀 تشغيل التطبيق

### الطريقة 1: تشغيل مباشر

```bash

```

ثم افتح المتصفح على: **http://localhost:5000**

### الطريقة 2: في الخلفية

```bash
python3 app.py &
```

---

## ⚡ المميزات الذكية

### 1. **ثلاث طرق عرض** 📚

- **المصحف** (mushaf): عرض تقليدي مثل المصحف المطبوع
- **قائمة** (list): كل آية في سطر منفصل
- **بطاقات** (card): عرض البطاقات الحديث

### 2. **خيارات خطوط متعددة** ✍️

- **أميري** (Amiri): الخط العثماني الكلاسيكي
- **القاهرة** (Cairo): خط عصري وواضح
- **Traditional Arabic**: خط ويندوز التقليدي
- **Scheherazade**: خط أنيق

### 3. **حجم خط قابل للتعديل** 🔍

- نطاق من 16px إلى 48px
- تحكم سلس بحجم النص

### 4. **الوضع الليلي** 🌙

- ضغطة زر واحدة
- ألوان مريحة للعين
- حفظ تلقائي للإعدادات

### 5. **بحث ذكي** 🔍

- بحث فوري أثناء الكتابة
- بحث في النص بدون تشكيل
- نتائج سريعة

### 6. **تصميم متجاوب** 📱

- يعمل على جميع الأجهزة
- قائمة جانبية قابلة للإخفاء
- تجربة مستخدم سلسة

## 🎨 الواجهة

### الصفحة الرئيسية

- **الهيدر**: إحصائيات حية (آيات، كلمات، حروف)
- **القائمة الجانبية**: فهرس السور + البحث
- **المحتوى**: عرض الآيات بالطريقة المفضلة
- **شريط الأدوات**: تحكم في الخط والعرض

### الألوان

- **النهاري**: ألوان فاتحة مريحة
- **الليلي**: ألوان داكنة هادئة
- **الأخضر الأساسي**: #1e7e34 (لون إسلامي)
- **البنفسجي الثانوي**: #7c4dff (لون عصري)

## 🔄 إضافة بيانات كاملة

```bash

```

أو ضع الملف مباشرة في:

```bash
python3 scripts/import_quran_smart.py --file data/sources/quran_Ayat/hafs_smart_v8.json
```

```bash
# إيقاف التطبيق الحالي

python3 app.py
```

## 🛠️ API Endpoints

### 1. الصفحة الرئيسية
```
GET /
```

### 2. قائمة السور
```
GET /api/surahs
```
الإخراج:
```json
[
  {
    "number": 1,
    "name": "الفاتحة",
    "ayah_count": 7
  }
]
```

### 3. آيات سورة
```
GET /api/surah/<رقم_السورة>
```

### 4. البحث
```
GET /api/search?q=<كلمة_البحث>
```

### 5. الإحصائيات
```
GET /api/stats
```
