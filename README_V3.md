## 🚀 كيفية التشغيل

### الطريقة الأسهل (موصى بها):

1. **حمّل الملف المضغوط** من الرابط أعلاه
2. **فك الضغط** في مجلد جديد
3. **ضع ملف قاعدة البيانات** `quran.db` في نفس المجلد
4. **اضغط مرتين** على `RUN_APP_V3.bat`

✅ سيقوم الملف تلقائياً بـ:
- فحص Python
- تثبيت PyQt6 إذا لزم
- تشغيل التطبيق

### الطريقة اليدوية:

```bash
# 1. تثبيت المتطلبات
pip install PyQt6

# 2. تشغيل التطبيق
python quran_app_v3_ultimate.py
```

## 🎨 الميزات الرئيسية

### 1. نظام ألوان التجويد المحسّن
- 15 حكم تجويد ملون
- الحروف متصلة بشكل طبيعي (CSS متقدم)
- تلميحات تفاعلية عند المرور بالماوس

### 2. التنقل السهل
- **الأسهم** ↑↓ أو ←→ للتنقل آية بآية
- **سكرول الماوس** للتصفح السريع
- **أزرار** سابق/تالي مرئية

### 3. عرض شامل
- **7 تابات مختلفة**: نص قرآني، تفسير، ترجمة، إعراب، صرف، موضوعات، بحث
- **3 أنواع عرض**: تجويد ملون (افتراضي)، عادي، إملائي
- **3 تفاسير**: الميسر، السعدي، البغوي
- **ترجمتان**: English, Français

### 4. بحث متقدم
- بحث في النص القرآني
- بحث في التفسير
- بحث بالموضوعات
- نتائج منظمة وتفاعلية

### 5. ذكاء اصطناعي
- **اكتشاف تلقائي** لبنية قاعدة البيانات
- **توافق مع أي schema** لقاعدة البيانات
- **حفظ تلقائي** لآخر موضع قراءة
