# 📖 تطبيق القرآن الكريم الاحترافي 2.0

<div dir="rtl">

## 🌟 نظرة عامة

تطبيق احترافي متكامل لتصفح القرآن الكريم، مبني من الصفر بتقنيات حديثة وتصميم راقي.

### ✨ الميزات الرئيسية

- **شجرة ديناميكية ذكية** - تصفح السور والآيات بسهولة
- **تابات متعددة المستويات** - تنظيم احترافي للمحتوى
- **بحث متقدم** - 4 أنماط بحث (ذكي، بالجذور، بالإعراب، بالوزن)
- **ألوان Claude الهادئة** - تصميم راقي ومريح للعين
- **تزامن كامل** - جميع المكونات تعمل بتناغم
- **أداء محسّن** - لا حدود للنتائج، سرعة فائقة
- **توافق عالي** - يدعم PyQt6 و PyQt5

---

## 🚀 البدء السريع

### المتطلبات

1. **Python 3.8+** - [تحميل من هنا](https://www.python.org/downloads/)
2. **PyQt6 أو PyQt5** - يُثبت تلقائياً
3. **قاعدة البيانات** - ملف `.db`

### التثبيت السريع

#### الطريقة الأولى (موصى بها):
```bash
# افتح CMD في مجلد التطبيق
RUN_APP.bat
```
> سيقوم الملف بفحص وتثبيت كل شيء تلقائياً!

#### الطريقة الثانية (يدوياً):
```bash
# 1. تثبيت المكتبات
pip install PyQt6

# 2. تشغيل التطبيق
python quran_app_ultimate.py
```

## 🔍 أنماط البحث

### 1. البحث الذكي 🔍
بحث نصي مباشر في القرآن الكريم

```
مثال: "الرحمن"
```

### 2. البحث بالجذور 🌱
البحث عن كلمات من نفس الجذر

```
مثال: "ك ت ب"
النتائج: كَتَبَ، كِتَاب، كَاتِب، مَكْتُوب...
```

### 3. البحث بالإعراب 📝
البحث حسب الموقع الإعرابي

```
مثال: "مفعول به"
```

### 4. البحث بالوزن ⚖️
البحث حسب الوزن الصرفي

```
مثال: "فَعَّل"
```
