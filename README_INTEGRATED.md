  - الجنة والنار
  - الرحمة والمغفرة
  - الدعاء والذكر

- عرض منظم للنتائج

### 🔍 **بحث متقدم**

- شجرة ديناميكية للسور والآيات
- تحميل كسول للآيات (Lazy Loading)

### 📖 **عرض شامل**

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Python 3.8 أو أحدث
- PyQt6 أو PyQt5

### خطوات التثبيت

#### 1. **تثبيت المكتبات**

```bash
pip install -r requirements.txt
```

أو يدوياً:

```bash
pip install PyQt6
# أو
pip install PyQt5
```

#### 2. **وضع قواعد البيانات**

ضع ملف واحد أو أكثر من هذه الملفات في نفس مجلد التطبيق:
- `quran_ultimate_final.db` (موصى به)
- `surah_database_app_v32.db`
- `Quran_Crystalline.db`

**ملاحظة**: يمكنك وضعها في المسار `C:\quran9\` أيضاً

#### 3. **تشغيل التطبيق**

**الطريقة السهلة (Windows):**
```
اضغط مرتين على: RUN_INTEGRATED.bat
```

**الطريقة اليدوية:**
```bash
python quran_app_ultimate_integrated.py
```

## 🐛 الأخطاء الشائعة وحلولها

### مشكلة: "لم يتم العثور على قاعدة بيانات"
**الحل**:
1. تأكد من وجود ملف `.db` في نفس المجلد
2. أو ضعه في `C:\quran9\`
3. تأكد من أن حجم الملف > 1 MB

### مشكلة: "ModuleNotFoundError: No module named 'PyQt6'"
**الحل**:
```bash
pip install PyQt6
# أو
pip install PyQt5
```

### مشكلة: التطبيق بطيء
**الحل**:
1. شغّل الفهرسة: `python create_indexes.py`
2. استخدم SSD
3. أغلق البرامج الثقيلة
