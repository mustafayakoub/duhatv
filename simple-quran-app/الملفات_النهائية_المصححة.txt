⚠️  هام: اتبع الخطوات بالترتيب!

────────────────────────────────────────────────────────────────────────────
✓ Python 3.6 أو أحدث مثبّت
✓ Flask مثبّت (pip install flask)
✓ ملفات القواعد موجودة في C:\quran11\:
  - Quran.db
  - Quran_irab_sarf.db

الخطوة 2: تحميل الملفات
────────────────────────────────────────────────────────────────────────────
✓ حمّل جميع الملفات (انظر القسم 3)
✓ ضعها في: C:\quran11\simple-quran-app\

الخطوة 3: تنظيف وإعادة البناء (حل مشكلة التكرار)
────────────────────────────────────────────────────────────────────────────
1. افتح مجلد: C:\quran11\simple-quran-app
2. اضغط مرتين على: START_CLEAN_REBUILD.bat
3. انتظر حتى تكتمل العملية (1-2 دقيقة)
4. تأكد من رؤية:
   السور: 114 ✅
   الآيات: 6,236 ✅
   الكلمات: 77,432 ✅

الخطوة 4: تشغيل التطبيق
────────────────────────────────────────────────────────────────────────────

2. انتظر حتى ترى: "Running on http://0.0.0.0:5000"
3. افتح المتصفح على: http://localhost:5000
