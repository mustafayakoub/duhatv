✨ تطبيق ويب بسيط لعرض بيانات القرآن الكريم من 3 قواعد بيانات SQLite

المميزات:
  ✅ بسيط جداً - بدون Docker أو تعقيد
  ✅ يشتغل من أول مرة - فقط 3 خطوات
  ✅ واجهة عربية جميلة مع بحث سريع
  ✅ يعرض: النص القرآني، الترجمات، الإعراب والصرف


═══════════════════════════════════════════════════════════════════════════════
                      🚀 التشغيل السريع (3 خطوات)
═══════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│ 1️⃣  ضع قواعد البيانات في C:\quran11\                                        │
└──────────────────────────────────────────────────────────────────────────────┘

    انسخ الملفات الثلاثة إلى:

    C:\quran11\
    ├── quran_ultimate_final.db      ← الترجمات (81,068 ترجمة)
    ├── surah_database_app_v32.db    ← الإعراب والصرف (77,432 كلمة)
    └── Quran_Crystalline.db         ← المحتوى (1,036,520 سجل)


┌──────────────────────────────────────────────────────────────────────────────┐
│ 2️⃣  اضغط مرتين على RUN.bat                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

    📁 ابحث عن الملف: RUN.bat
    🖱️  اضغط عليه مرتين

    سيقوم بـ:
      ✓ التحقق من Python
      ✓ تثبيت المكتبات اللازمة
      ✓ تشغيل التطبيق تلقائياً
      ✓ فتح المتصفح


┌──────────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  استمتع!                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

    المتصفح سيفتح تلقائياً على:
    🌐 http://localhost:5000

    إذا لم يفتح، افتحه يدوياً وادخل الرابط أعلاه.


═══════════════════════════════════════════════════════════════════════════════
                          📋 إذا واجهت مشاكل
═══════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│ ❌ رسالة: "Python غير مثبت"                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

    الحل:
    1. حمّل Python من: https://www.python.org/downloads/
    2. أثناء التثبيت، فعّل "Add Python to PATH" ✓
    3. أعد تشغيل RUN.bat


┌──────────────────────────────────────────────────────────────────────────────┐
│ ❌ رسالة: "لا توجد بيانات"                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

    الحل:
    تأكد من وضع قواعد البيانات الثلاث في المسار:
    C:\quran11\

    تحقق من أسماء الملفات (يجب أن تكون كما في الخطوة 1 بالضبط)


┌──────────────────────────────────────────────────────────────────────────────┐
│ ❌ رسالة: "المنفذ 5000 مشغول"                                                │
└──────────────────────────────────────────────────────────────────────────────┘

    الحل:
    1. افتح app.py بمحرر نصوص
    2. اذهب للسطر الأخير
    3. غيّر 5000 إلى 5001 أو أي رقم آخر
    4. احفظ وشغّل من جديد


═══════════════════════════════════════════════════════════════════════════════
                           🔗 الروابط المفيدة
═══════════════════════════════════════════════════════════════════════════════

    📖 الصفحة الرئيسية:
       http://localhost:5000/

    📄 سورة البقرة (مثال):
       http://localhost:5000/surah/2

    🔍 البحث عن "الله":
       http://localhost:5000/api/search?q=الله

    📊 إحصائيات قواعد البيانات:
       http://localhost:5000/api/stats

═══════════════════════════════════════════════════════════════════════════════
                         ⚙️  طريقة التشغيل اليدوية
═══════════════════════════════════════════════════════════════════════════════

    إذا كنت تفضل التشغيل اليدوي:

    1. افتح PowerShell أو CMD
    2. اذهب لمجلد التطبيق:
       cd C:\path\to\simple-quran-app

    3. ثبّت المكتبات:
       pip install -r requirements.txt

    4. شغّل التطبيق:
       python app.py

    5. افتح المتصفح:
       http://localhost:5000
