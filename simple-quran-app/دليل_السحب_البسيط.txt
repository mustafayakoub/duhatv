═══════════════════════════════════════════════════════════════════════
                      ✨ الطريقة الأولى - الأسهل!
                      (اضغط مرتين فقط!)
═══════════════════════════════════════════════════════════════════════

1. ابحث عن الملف:
   📄 سحب_آخر_التحديثات.bat

2. اضغط عليه مرتين (Double Click)

3. انتظر... سيظهر لك:
   ✅ تم سحب التحديثات بنجاح!

4. انتهى! 🎉


═══════════════════════════════════════════════════════════════════════
                    📋 الطريقة الثانية - يدوياً
                    (باستخدام الأوامر)
═══════════════════════════════════════════════════════════════════════

الخطوة 1: افتح PowerShell أو CMD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    📌 كيف؟
       • اضغط Windows + R
       • اكتب: cmd
       • اضغط Enter


الخطوة 2: انتقل لمجلد المشروع
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    اكتب (غيّر المسار حسب موقع المشروع عندك):

    cd C:\Users\YourName\duhatv\simple-quran-app

    مثلاً:
    cd C:\Users\Mustafa\duhatv\simple-quran-app


الخطوة 3: اسحب التحديثات
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    انسخ هذا الأمر والصقه في CMD:

    git pull origin claude/multilingual-programming-setup-011CUhD7ZhvWxnVqEUQ9rTsR

    ثم اضغط Enter

    ملاحظة: يمكنك نسخ الأمر من هنا بالضبط!


الخطوة 4: تأكد من النجاح
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    سترى رسالة مثل:

    From ...
       fa63bdb..722c227  claude/multilingual-programming-setup-011CUhD7ZhvWxnVqEUQ9rTsR
    Updating fa63bdb..722c227
    Fast-forward
     migrate_words_smart.py | 327 ++++++++++++++++++++++++++
     كيفية_النقل.txt        | 232 +++++++++++++++++
     SUMMARY.md             | 190 ++++++++++++++
     3 files changed, 749 insertions(+)

    معناها: تم بنجاح! ✅


═══════════════════════════════════════════════════════════════════════
                    🐙 الطريقة الثالثة - GitHub Desktop
                    (إذا كنت تفضل واجهة رسومية)
═══════════════════════════════════════════════════════════════════════

1. حمّل GitHub Desktop من:
   https://desktop.github.com/

2. افتح المشروع فيه

3. اضغط زر "Fetch origin" أعلى اليمين

4. ثم اضغط "Pull origin"

5. انتهى! ✅


═══════════════════════════════════════════════════════════════════════
                         ❓ إذا واجهتك مشكلة
═══════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────┐
│ المشكلة 1: "fatal: not a git repository"                         │
└───────────────────────────────────────────────────────────────────┘

    الحل:
    تأكد أنك في المجلد الصحيح!

    اكتب:
    cd C:\المسار\الصحيح\duhatv\simple-quran-app


┌───────────────────────────────────────────────────────────────────┐
│ المشكلة 2: "fatal: couldn't find remote ref"                     │
└───────────────────────────────────────────────────────────────────┘

    الحل:
    اسحب كل الـ branches أولاً:

    git fetch --all

    ثم:
    git pull origin claude/multilingual-programming-setup-011CUhD7ZhvWxnVqEUQ9rTsR


┌───────────────────────────────────────────────────────────────────┐
│ المشكلة 3: "You have unstaged changes"                           │
└───────────────────────────────────────────────────────────────────┘

    الحل:
    عندك تغييرات لم تحفظها.

    إما:
    1. احفظها: git stash
    2. أو تجاهلها: git reset --hard


┌───────────────────────────────────────────────────────────────────┐
│ المشكلة 4: اسم الـ branch طويل جداً!                             │
└───────────────────────────────────────────────────────────────────┘

    الحل السهل:
    استخدم الملف التلقائي:

    اضغط مرتين على: سحب_آخر_التحديثات.bat


═══════════════════════════════════════════════════════════════════════
                       📦 الملفات التي ستحصل عليها
═══════════════════════════════════════════════════════════════════════

بعد السحب، سيكون عندك:

    simple-quran-app/
    ├── ✨ migrate_words_smart.py       (جديد!)
    ├── ✨ كيفية_النقل.txt              (جديد!)
    ├── ✨ SUMMARY.md                   (جديد!)
    ├── 📄 سحب_آخر_التحديثات.bat       (هذا الملف)
    ├── 📖 دليل_السحب_البسيط.txt       (هذا الدليل)
    └── ... (بقية الملفات)


═══════════════════════════════════════════════════════════════════════
                         🎯 ماذا بعد السحب؟
═══════════════════════════════════════════════════════════════════════

1. تأكد من وجود الملفات الجديدة:
   ✓ migrate_words_smart.py
   ✓ كيفية_النقل.txt
   ✓ SUMMARY.md

2. اقرأ الدليل:
   📖 كيفية_النقل.txt

3. شغّل السكريبت:
   python migrate_words_smart.py

4. استمتع! 🎉


═══════════════════════════════════════════════════════════════════════
                      💡 نصائح سريعة
═══════════════════════════════════════════════════════════════════════

✅ استخدم الملف التلقائي (سحب_آخر_التحديثات.bat) - الأسهل!

✅ إذا فشل، جرب:
   git fetch --all
   ثم أعد المحاولة

✅ يمكنك نسخ الأمر كاملاً من هذا الملف ولصقه في CMD

✅ Git Desktop أسهل إذا كنت لا تحب الأوامر


═══════════════════════════════════════════════════════════════════════
                    🔄 كيف تسحب التحديثات مستقبلاً؟
═══════════════════════════════════════════════════════════════════════

في أي وقت تريد آخر التحديثات:

    1. اضغط مرتين على: سحب_آخر_التحديثات.bat

    أو

    2. افتح CMD واكتب:
       cd simple-quran-app
       git pull origin claude/multilingual-programming-setup-011CUhD7ZhvWxnVqEUQ9rTsR
