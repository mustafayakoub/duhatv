# 🌙 تطبيق القرآن الكريم - ويب بسيط

تطبيق ويب بسيط وسريع لعرض بيانات القرآن الكريم من ثلاث قواعد بيانات SQLite.

---

## ✨ المميزات

- ✅ **بسيط جداً** - لا Docker، لا تعقيد!
- ✅ **يشتغل من أول مرة** - فقط شغّل RUN.bat
- ✅ **واجهة عربية جميلة** - تصميم عصري وسهل الاستخدام
- ✅ **بحث سريع** - ابحث في القرآن مباشرة
- ✅ **ثلاث تبويبات**:
  - 📖 النص القرآني
  - 🌐 الترجمات
  - 📚 الإعراب والصرف
- ✅ **دعم كامل للعربية** - RTL وخطوط عربية

---

## 🚀 التشغيل السريع (3 خطوات فقط!)

### 1️⃣ ضع قواعد البيانات

انسخ قواعد البيانات الثلاث إلى `C:\quran11\`:

```
C:\quran11\
├── quran_ultimate_final.db
├── surah_database_app_v32.db
└── Quran_Crystalline.db
```

### 2️⃣ شغّل التطبيق

**طريقة 1 (الأسهل):** اضغط مرتين على `RUN.bat`

**طريقة 2 (يدوياً):**
```bash
# في PowerShell أو CMD:
cd simple-quran-app
pip install -r requirements.txt
python app.py
```

### 3️⃣ افتح المتصفح

اذهب إلى: **http://localhost:5000**

## 🔧 حل المشاكل

### ❌ "Python غير مثبت"
- حمّل Python من: https://www.python.org/downloads/
- **مهم:** اختر "Add Python to PATH" أثناء التثبيت

### ❌ "لا توجد بيانات"
- تأكد من وضع قواعد البيانات في `C:\quran11\`
- تأكد من أسماء الملفات صحيحة

### ❌ "المنفذ 5000 مشغول"
- غيّر المنفذ في `app.py` السطر الأخير:
  ```python
  app.run(debug=True, host='0.0.0.0', port=5001)  # بدل 5000 إلى 5001
  ```
