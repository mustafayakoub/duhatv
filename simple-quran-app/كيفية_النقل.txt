✅ تم الاتفاق على البنية الدقيقة:
   • 114 سورة
   • 6,236 آية
   • 77,432 كلمة (بالضبط - بدون البيانات الوصفية)
   • البسملات: محسوبة في الفاتحة فقط
   • البسملات المعروضة: 113 (كل السور ماعدا التوبة)

✅ تم إنشاء سكريبت نقل ذكي:
   • migrate_words_smart.py
   • يستخدم INNER JOIN لضمان الدقة
   • يستبعد البيانات الوصفية تلقائياً

┌───────────────────────────────────────────────────────────────────────┐
│ الخطوة 1: تأكد من وجود قواعد البيانات                                │
└───────────────────────────────────────────────────────────────────────┘

    يجب أن يكون لديك في C:\quran11\:

    C:\quran11\
    ├── surah_database_app_v32.db    ← DB2 (الإعراب والصرف)
    └── quran_unified.db             ← القاعدة الموحدة (الهدف)

    ملاحظة: إذا لم تكن quran_unified.db موجودة، يجب إنشاؤها أولاً
    باستخدام سكريبتات النقل السابقة (السور والآيات).


┌───────────────────────────────────────────────────────────────────────┐
│ الخطوة 2: شغّل سكريبت النقل                                          │
└───────────────────────────────────────────────────────────────────────┘

    في PowerShell أو CMD:

    cd C:\path\to\simple-quran-app
    python migrate_words_smart.py

    أو ببساطة اضغط مرتين على:
    migrate_words_smart.py (إذا كان Python مثبت)


┌───────────────────────────────────────────────────────────────────────┐
│ الخطوة 3: راقب التقدم                                                 │
└───────────────────────────────────────────────────────────────────────┘

    سيعرض السكريبت:
    ✓ عدد الكلمات المقروءة من DB2
    ✓ نسبة التقدم (كل 1000 كلمة)
    ✓ الوقت المستغرق
    ✓ عينة من البيانات المنقولة


═══════════════════════════════════════════════════════════════════════
                          🔍 ماذا يفعل السكريبت؟
═══════════════════════════════════════════════════════════════════════

1️⃣  يقرأ من DB2 (surah_database_app_v32.db):
    • يستخدم INNER JOIN مع word_content_irab
    • يضمن الحصول على 77,432 كلمة فقط
    • يستبعد تلقائياً:
      - 6,236 نص آية كامل (wordNo=0)
      - 111 اسم سورة (ayahNo=0)
      - 112 رقم آية (ayahNo=-1)
      - 4 بسملات إضافية

2️⃣  ينقل إلى quran_unified.db:
    • الكلمات (words table)
      - word_text: الكلمة بالحركات
      - word_simple: الكلمة بدون حركات
      - root_text: الجذر
      - word_position: موقع الكلمة في الآية

    • الإعراب (irab table)
      - irab_text: الإعراب المشكّل

    • الصرف (sarf table)
      - sarf_text: التحليل الصرفي

3️⃣  يتحقق من الدقة:
    • يعد الكلمات المنقولة
    • يعرض عينة من البيانات
    • يتأكد من العدد الدقيق: 77,432


═══════════════════════════════════════════════════════════════════════
                           📊 النتيجة المتوقعة
═══════════════════════════════════════════════════════════════════════

بعد اكتمال النقل، ستحتوي quran_unified.db على:

    ┌─────────────────┬──────────────┬─────────────────────────┐
    │     الجدول      │     العدد    │         الوصف          │
    ├─────────────────┼──────────────┼─────────────────────────┤
    │ surahs          │ 114          │ السور                  │
    │ ayahs           │ 6,236        │ الآيات                 │
    │ words           │ 77,432       │ الكلمات                │
    │ irab            │ ~77,432      │ الإعراب                │
    │ sarf            │ ~77,432      │ الصرف                  │
    └─────────────────┴──────────────┴─────────────────────────┘


═══════════════════════════════════════════════════════════════════════
                        ⚡ تحسينات السكريبت
═══════════════════════════════════════════════════════════════════════

✨ كاش الآيات (Ayah Cache):
   • يخزن ayah_id في الذاكرة
   • يقلل استعلامات القاعدة من 77,432 إلى 6,236
   • يسرع النقل بشكل كبير

✨ Commit على دفعات:
   • Commit كل 1000 كلمة
   • يحافظ على الأداء
   • يتجنب فقدان البيانات عند الانقطاع

✨ تعطيل Foreign Keys مؤقتاً:
   • يسرع الإدخال
   • يعيد تفعيلها بعد الانتهاء

✨ معالجة الأخطاء:
   • Rollback تلقائي عند الخطأ
   • رسائل خطأ واضحة
   • تقارير مفصلة
